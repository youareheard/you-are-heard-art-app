# You Are Heard — Art & Expression

A small, separate web app for artwork submissions and a manually moderated public gallery. Visitors can submit an image, optional title/caption/display name, and must confirm they have permission to share it. Submissions are private by default. The public feed shows approved submissions only. The site owner reviews items at `/admin`.

## Features
- Responsive public gallery and submission form
- Anonymous display name by default
- JPG, PNG, WEBP, and GIF uploads, maximum 8 MB
- Server-side file type allowlist and upload size limit
- Private pending/rejected submissions; public image route serves approved work only
- Password-protected moderation dashboard with approve, reject, and permanent delete actions
- Rate limiting, secure cookie, signed admin session, security headers
- SQLite database and upload directory on persistent disk

## Deploy to Render

**Persistence matters:** this app stores the database and uploads on disk. It needs a persistent disk mounted at `/var/data`; without one, data may be lost on restart or redeploy. The included `render.yaml` defines a Starter web service and a 1 GB disk. Review the current Render pricing before deploying.

1. Create a new private GitHub repository and upload the contents of this folder (not the parent folder).
2. In Render, choose **New → Blueprint** and connect that repository. Render reads `render.yaml`.
3. During setup, set `ADMIN_PASSWORD` to a strong unique password of at least 14 characters. `SESSION_SECRET` is generated by the Blueprint; if setting manually, use a random secret of at least 32 characters.
4. Deploy and wait for `/health` to return `{"ok":true}`.
5. Visit the new Render URL. The public gallery and form are at `/`; owner review is at `/admin`.
6. Test with a non-sensitive sample image. Check that it remains absent from the public gallery until approved.

## Add it to Shopify

This first version is hosted as a separate web app. In Shopify Admin, create a page named **Art & Expression** and add a prominent link/button to the Render app URL. This opens the hosted app in its own page. Avoid embedding until you've tested mobile layout, privacy messaging, and Shopify's iframe restrictions.

Example link label: **Visit Art & Expression and share your work**.

## Before launch

- Replace or supplement the starter privacy wording with a reviewed privacy notice explaining storage, who can access submissions, retention/deletion, and contact details.
- Publish clear community guidelines and a takedown contact.
- Consider an age policy and a process for reporting harmful or identifying content.
- Tell contributors that anonymous display does not mean the hosting operator cannot access submissions; do not promise confidentiality or anonymity beyond what is actually provided.
- The app does not collect email addresses or use AI moderation. Manual approval is required.
- Uploads are private while pending/rejected and only approved images are served publicly. Admin preview requires sign-in.
- The app does not currently send submitter notifications, support video/audio/text-file uploads, or provide a submitter account/claim process.

## Local development

Requires Node.js 20+.

```bash
npm install
export ADMIN_PASSWORD='use-a-unique-long-password-here'
export SESSION_SECRET="$(node -e "console.log(require('crypto').randomBytes(32).toString('hex'))")"
npm start
```

Open `http://localhost:3000`. Local data is stored in `./data` unless `DATA_DIR` is set.
